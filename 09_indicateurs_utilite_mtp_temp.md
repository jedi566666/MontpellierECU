# INDICATEURS D'UTILITÉ MTP

## Principe fondamental

**LE COURS EST UNE DONNÉE. L'UTILITÉ EST LE PROJET.**

Ne pas mesurer le succès avec : prix du token, market cap, TVL, nombre de pools, volume de trading

Mesurer le succès avec : nombre d'usages réels, nombre de biens/services disponibles, nombre de créateurs, nombre de commerces volontaires, nombre d'échanges, nombre d'objets réutilisés, nombre de personnes utilisant réellement MTP

## INDICATEURS BLOCKCHAIN

| Indicateur | Description | Objectif minimum |
|------------|-------------|------------------|
| Transactions utiles | Transactions对应ant à des achats/services | >1000/mois |
| Wallets actifs | Wallets ayant efectué au moins 1 transaction utile par mois | >500 |
| Tokens en circulation | MTP effectivement utilisés | >70% |
| Contrats auditéurs | Smart contracts auditéurs par des experts | 2 audits/min |
