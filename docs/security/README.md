# Sécurité
[Politique de signalement](../../SECURITY.md) · [Avis de risque](../../RISK_NOTICE_FR.md).

Le contrôle du contrat est une reproduction de bytecode, pas une certification sans faille. Le scan documentaire du 25 septembre 2026 n'a trouvé aucun motif de secret connu dans 195 versions de fichiers texte de première partie ; il excluait dépendances, binaires, images/PDF et contenus d'archives. Il ne prouve pas l'absence de secrets.

Ne publier aucune clé, phrase de récupération ou donnée privée. Les dépendances suivies sur master nécessitent une migration contrôlée ; aucune réécriture d'historique n'est engagée dans cette édition documentaire.
