# Marketplace — prototype
[Préparer une annonce](https://mtptoken.pages.dev/echanges/).

Les annonces sont des brouillons conservés sur l'appareil. Le partage est manuel ; pas de publication serveur, de stock partagé ni de paiement automatique. Effacer les données du navigateur peut effacer les brouillons.

Avant extension : sauvegarde/export, règles de publication, modération, responsabilités, puis éventuel parcours de paiement distinct et explicitement validé.
