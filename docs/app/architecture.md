# MTP App / Monia
Monia rassemble les outils MTP dans une application Windows. La [release publique](https://github.com/jedi566666/MontpellierECU/releases/tag/v1.0.0) est 1.0 ; Monia 2.0 est une livraison locale non encore publiée.

La version locale 2 utilise Electron, avec contextIsolation et sandbox activés, nodeIntegration désactivé. Les annonces et messages locaux ne constituent pas une messagerie serveur ni une place de marché synchronisée. Aucun stockage de clés privées n'est annoncé.

Les sources de cette version locale ne sont pas encore intégrées à main. Avant nouvelle release : contrôler les liens, la licence, les binaires, les sources correspondantes et publier les SHA256. Les anciens liens Netlify sont indisponibles ; utiliser le [site actuel](https://mtptoken.pages.dev/).
