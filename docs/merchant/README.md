# Mode commerçant — prévu
Aucun réseau de commerçants acquis ni mode caisse opérationnel n'est annoncé.

Première étape : vérifier l'intérêt de volontaires, décrire un service réel et tester le parcours sans transaction. Toute utilisation commerciale ultérieure exige des conditions claires, des responsabilités identifiées et une validation adaptée. [Essai proposé](../PISTE-UTILITE-ARGENT-0.md).
