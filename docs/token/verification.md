# Vérifier le contrat
1. Vérifier Base et l'adresse complète du [contrat officiel](contract.md).
2. Lire le [rapport du 22 septembre](../preuves-contrat-2026-09-22/RAPPORT.md).
3. Télécharger l'[archive reproductible](../preuves-contrat-2026-09-22/MTP-PREUVE-BYTECODE-2026-09-22.zip), examiner verify.cjs, les paramètres du compilateur et les empreintes.
4. Distinguer correspondance de bytecode, revue du code et audit de sécurité exhaustif.

Les anciennes générations sont des artefacts historiques ; leurs propriétés ne doivent pas être attribuées au contrat actuel.
