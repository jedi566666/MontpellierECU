# MTP Live — bêta
[Ouvrir Live](https://mtptoken.pages.dev/live/).

Les données proviennent notamment de GeckoTerminal et DexScreener. Les historiques relient les clôtures disponibles ; ils n'inventent pas d'échanges intermédiaires. Les délais, absences et erreurs des services externes doivent rester visibles. Le prix d'une pool n'est pas un prix d'exécution garanti.

Priorités de maintenance : valeur numérique lisible, date du relevé, distinction entre cours et historique indisponible, reprise correcte après erreur.
