# Roadmap d'utilité
1. **De l'écran à l'abandon** : livrables créatifs validés et premier usage défini.
2. **MTP App** : version distribuée testée, sources et limites documentées.
3. **Marketplace** : annonces utiles, sauvegarde, publication et modération définies.
4. **Montpellier** : retours de volontaires sur des parcours réels.
5. **Occitanie** : extension des usages éprouvés.
6. **France** : adaptation selon les participants.
7. **Monde** : ouverture progressive, langues et parcours maintenus.

Aucune date, performance financière ou adoption acquise n'est promise. Les critères de passage sont la qualité, les ressources disponibles et les besoins observés.
