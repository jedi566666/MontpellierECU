# Écosystème

L’écosystème MTP s’organise autour de plusieurs outils publics complémentaires.

- **Site officiel** — identité, liens officiels et point d’entrée public.
- **MTP Live** — suivi de la blockchain, du marché et des pools.
- **MTP Wallet** — accès simplifié aux fonctions liées au wallet.
- **Marketplace MTP** — annonces d’objets, de services et de savoir-faire libellées en MTP.
- **MONIA** — application Windows reliant les principaux services de l’écosystème.
- **GitHub** — documentation publique, versions et transparence technique.

Les liens officiels sont maintenus dans le README principal. Les utilisateurs doivent vérifier les domaines et le contrat canonique avant toute interaction.
