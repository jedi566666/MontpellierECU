# MTP Ecosystem

[Version française](ECOSYSTEM_FR.md)

## Core layer

### Montpellier ECU (MTP)
The ERC-20 token deployed on Base connects the ecosystem's services and interfaces.

Canonical contract:

`0x50626097a780881d3dFf1Ff97579e6dAF965366B`

## Public interfaces

### Official website
https://mtp-coin.netlify.app/

The primary source for project identity, navigation and public access.

### MTP Live
https://mtplive.netlify.app/

A monitoring interface intended to make market and network activity easier to understand. Displayed data depends on third-party indexing and should always be cross-checked on-chain.

### MTP Wallet
https://mtpwallet.netlify.app/

A wallet-oriented interface for access to MTP-related functions. Users remain responsible for protecting their wallet credentials and validating transactions.

### Marketplace
A service layer for listings involving objects, services and skills priced in MTP. Its long-term role is to provide the ecosystem's primary non-speculative use case.

### MONIA
The official desktop application. Version 1.0 includes a portable distribution intended to reduce installation friction. MONIA is one access option within the ecosystem; it is not the ecosystem itself.

### Argent 0
A public philosophy and design direction built around the principle:

> Money is not an end. It is a means.

## Architecture principles

- MTP remains the central asset.
- Interfaces should remain optional and interoperable where possible.
- A user should not be forced to install MONIA to understand or access the project.
- Public data should be sourced from the blockchain or clearly identified providers.
- No interface should display fabricated market data when a provider is unavailable.
