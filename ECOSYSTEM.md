# Ecosystem

The MTP ecosystem is organized around complementary public tools.

- **Official Website** — identity, official links and public entry point.
- **MTP Live** — blockchain, market and pool monitoring.
- **MTP Wallet** — simplified access to wallet-related functions.
- **MTP Marketplace** — listings for objects, services and skills denominated in MTP.
- **MONIA** — Windows desktop application connecting the main ecosystem services.
- **GitHub** — public documentation, releases and technical transparency.

Official links are maintained in the main README. Users should verify domains and the canonical contract before interacting.
