## What is MTP?

Montpellier ECU (MTP) is an independent digital ecosystem built around an ERC-20 token deployed on Base. Its purpose is to give practical digital utility to objects, services and skills through a marketplace, wallet interfaces, network monitoring tools and user-facing software.

MTP is not presented as a guaranteed investment, a savings product or a promise of financial return. The project is developed openly, progressively and without venture-capital control.

## Strategic priorities

The project follows three durable principles:

1. **Useful liquidity** — improve market accessibility without promising or engineering a price increase.
2. **Real utility** — make MTP usable for concrete exchanges, services and access.
3. **Strong, truthful narrative** — express the Occitan roots and independent character of the project without misleading claims.

The complete execution framework is available in [ROADMAP.md](ROADMAP.md).

## What MTP is not

- Not a guaranteed-return product.
- Not a promise that the token price will rise.
- Not a bank deposit or stable-value asset.
- Not a substitute for independent legal, tax or financial advice.
- Not a project whose credibility depends on hiding blockchain data or fabricating activity.

## Public-development rule

Every major feature should move through four states:

`Proposed → Built → Tested → Publicly documented`

Planned features must never be presented as already available.
