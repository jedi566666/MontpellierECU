# Remerciements

Montpellier ECU (MTP) est un projet indépendant construit avec l’appui de technologies open source modernes et d’outils de développement assisté par intelligence artificielle.

## OpenAI et ChatGPT

Nous adressons nos sincères remerciements aux équipes d’OpenAI pour la création de ChatGPT. Cet outil a accompagné le projet pendant les phases de réflexion, de documentation, d’architecture logicielle, de prototypage d’interfaces, de rédaction technique et de contrôle qualité itératif.

Ces remerciements n’impliquent **aucun partenariat, soutien officiel, parrainage ou affiliation** entre OpenAI et Montpellier ECU. Ils expriment simplement une gratitude sincère envers un outil qui a contribué à transformer des idées en un écosystème fonctionnel.

## Écosystème open source

Nous remercions également les développeurs, mainteneurs et contributeurs des technologies open source utilisées dans le projet.

## Plateformes d’hébergement et de collaboration

Nous remercions GitHub pour l’hébergement du code et de la documentation publique, Netlify pour le déploiement web, ainsi que Base pour l’infrastructure blockchain publique sur laquelle le token MTP est déployé.

## Contributeurs

Merci à toutes les personnes qui testent, signalent des problèmes, partagent des retours constructifs ou contribuent au projet de bonne foi.
