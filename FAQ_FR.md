# Questions fréquentes

## Qu’est-ce que MTP ?
Montpellier ECU (MTP) est un token ERC-20 déployé sur Base et relié à un écosystème d’outils publics développé de manière indépendante.

## MTP est-il un produit d’investissement ?
Aucun rendement financier n’est promis. MTP est présenté comme un crypto-actif orienté vers l’utilité et demeure risqué.

## OpenAI est-il affilié à MTP ?
Non. OpenAI et ChatGPT sont remerciés pour l’aide apportée par l’outil. Cela n’implique aucune affiliation, approbation, sponsorisation ou partenariat.

## Où vérifier le token ?
Utiliser le contrat canonique indiqué dans le README et le vérifier sur BaseScan.

## Tous les éléments de la roadmap sont-ils disponibles ?
Non. Seules les fonctions explicitement indiquées comme disponibles doivent être considérées comme publiées.

## Où signaler un bug ?
Utiliser les issues GitHub pour les signalements publics non sensibles et suivre `SECURITY_FR.md` pour les sujets de sécurité.
