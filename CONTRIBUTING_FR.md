# Contribuer

[English version](CONTRIBUTING.md)

Les contributions améliorant la clarté, la sécurité, l’accessibilité, la traduction ou l’exactitude factuelle sont bienvenues.

## Avant de proposer une contribution

- Rechercher les issues existantes.
- Ne jamais inclure de secret de wallet ni d’information personnelle.
- Séparer les corrections factuelles des propositions stratégiques.
- Citer une source on-chain ou officielle lors de la modification d’une donnée technique.
- Maintenir la cohérence entre les documents français et anglais concernés.

## Exigences d’une pull request

Une pull request doit expliquer :

1. ce qui change ;
2. pourquoi le changement est nécessaire ;
3. comment il a été vérifié ;
4. si le fichier dans l’autre langue doit également être mis à jour.

## Règles de contenu

Les contributions ne doivent pas introduire :

- de promesse de rendement garanti ;
- de partenariat ou statistique inventés ;
- d’adresse de pool non vérifiée ;
- d’instructions encourageant une activité de marché trompeuse ;
- de clé privée, phrase de récupération ou information de doxxing ;
- de contenu propriétaire copié sans autorisation.

## Étiquettes recommandées

- `documentation`
- `translation`
- `security`
- `bug`
- `proposal`
- `needs-verification`
