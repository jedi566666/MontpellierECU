# Roadmap

This roadmap describes intentions, not guarantees. Priorities may change according to security, technical constraints, user feedback and available resources.

## Available

- MTP token deployed on Base
- Official website
- MTP Live monitoring terminal
- MTP Wallet interface
- MTP Marketplace
- MONIA Windows desktop application
- Public bilingual documentation

## Current priorities

- Improve reliability, clarity and accessibility of existing products
- Expand real marketplace usage
- Strengthen security documentation and public trust resources
- Improve liquidity information and pool visibility
- Build a first local network of users and merchants

## Exploratory work

- Mobile experience
- Additional wallet integrations
- QR and point-of-sale use cases
- Community contribution mechanisms
- Governance models

No exploratory feature is considered launched until it is publicly released and documented.
