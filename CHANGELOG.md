# Changelog

All notable documentation changes will be recorded here.

## [1.0.0] — 2026-07-25

### Added

- Initial bilingual MTP Master Plan repository.
- Public vision and phased roadmap.
- Ecosystem map and product-status table.
- Token, liquidity, governance, security and risk documentation.
- French and English FAQ and contribution guides.
- GitHub issue templates and repository metadata.

### Policy decisions

- MTP is presented as an ecosystem asset, not a guaranteed investment.
- MONIA is documented as an optional ecosystem interface.
- Personal wallet profiles are not promoted for security reasons.
- Advanced staking or governance mechanisms remain unlaunched and exploratory.
